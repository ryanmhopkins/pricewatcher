How it works

Track the pricing signals that actually matter.

PriceWatcher combines scheduled monitoring, pricing-focused extraction, change classification, history, and outbound alerts in one narrow workflow.

Monitoring

Flexible check cadence

Run checks hourly, every 6 hours, every 12 hours, daily, or weekly. Pause and resume any monitor without losing its history.

Detection

Pricing-aware extraction

PriceWatcher prioritizes pricing, billing periods, plans, seats, credits, usage, limits, and packaging language rather than every HTML change.

Intelligence

Concise summaries

When the data supports it, raw diffs are reduced to useful summaries such as “$29 → $39” and classified by change type and severity.

Workflow

Review and history

See previous changes and snapshots, mark important changes reviewed or unreviewed, copy the diff, and export your monitoring data.

Alerts

Webhook delivery

Send pricing-change events to Slack, Discord, Zapier, Make, n8n, or your own HTTPS endpoint. Test webhooks directly from settings.

Operations

Health visibility

Failed fetches are surfaced with error details. Each monitor shows its last check, next scheduled check, status, snapshot count, and change count.

Built narrowly on purpose

Not another giant competitive-intelligence suite.

The product does one job: monitor competitor pricing pages and reduce the work required to understand what changed. It does not try to become your CRM, project manager, or analytics warehouse.

Lower noise

Pricing-related text is isolated before snapshots are compared.

Clear evidence

Raw added and removed text stays available behind each summary.

Easy exit

Export the monitoring state and change history as JSON whenever you want.

Security

Private-beta protections are already in place.

The current build uses protected app sessions, row-level security, server-side database access, rate limits, SSRF protections, security headers, no-indexing, and maintenance jobs for stale session data.
