Privacy

Privacy information.

This page describes the current PriceWatcher private beta. It should be updated before a broader commercial launch or when the product begins collecting additional user or billing data.

Information PriceWatcher stores

PriceWatcher stores the competitor monitor information you enter, including monitor names, public URLs, selected check frequency, monitor status, optional webhook URLs, pricing-page snapshots, detected changes, review state, timestamps, and operational error information.

The private-beta access system also stores hashed access configuration and hashed, expiring session tokens. The raw access code and raw session token are not stored in the monitoring tables.

How the information is used

Stored information is used to perform scheduled checks, compare pricing-page snapshots, display monitoring history, deliver configured webhook alerts, operate the private-beta access system, prevent abuse, troubleshoot failed checks, and maintain the service.

Third-party services

The current product uses infrastructure providers including Vercel for web hosting and Supabase for database, scheduled jobs, and server-side functions. If you configure a webhook, PriceWatcher transmits the relevant change event to the HTTPS endpoint you provide.

Competitor pages

PriceWatcher fetches public URLs supplied by the user. Page content relevant to monitoring may be stored as snapshots for comparison and history. You are responsible for choosing URLs you are permitted to monitor and for using PriceWatcher in accordance with applicable law and website terms.

Payments

Billing is not currently enabled in the private beta, so PriceWatcher does not currently collect payment-card information. If paid billing is introduced, payment information is expected to be handled by a payment processor rather than stored directly by PriceWatcher.

Retention

The application currently includes automated maintenance that removes expired beta sessions and stale rate-limit records. Old monitoring snapshots may be automatically removed after the configured retention period. Removing a monitor also removes its associated snapshots and change history from the application database.

Security

The private beta uses row-level security, server-side database access, rate limiting, restricted monitoring targets, security headers, protected app sessions, and other technical safeguards. No system can guarantee absolute security.

Your choices

You can pause or remove monitors from the dashboard and export monitoring data as JSON. If the product expands to individual accounts, additional access, deletion, and privacy controls should be added to this policy.

Changes to this notice

This privacy notice may change as the private beta evolves. Material product changes such as billing, user accounts, analytics, or additional notification providers should be reflected here before public launch.

Private-beta notice — this page is practical product documentation, not a substitute for legal advice. A commercial launch should include review appropriate to the jurisdictions and customers PriceWatcher serves.
